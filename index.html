01 — About me

Skilled in building
webpages that work

I am a full-stack developer with expertise in designing, developing and deploying scalable, secure and efficient web applications — both the front end people see and the back end that keeps it running. I work comfortably across both sides, and I have built a lot of full-stack projects end to end.

My work is driven by three things: function that holds up under real traffic, interfaces that make sense on a phone first, and delivery that finishes. I have taken projects from a blank folder to a deployed product for resorts, NGOs, training organisations and freelance clients.

  • Front end in React, Next.js, Bootstrap and hand-written CSS
  • Back end in Python (Django, Flask), PHP, Laravel and Node.js
  • Databases, authentication, payments and cloud deployment handled end to end
  • Teaching and mentoring junior developers through code instruction

How I work

Result driven, collaborative, and always learning. I would rather ship something small that works than something large that almost does — and I document what I hand over.
